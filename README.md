# Clinical Programming & SAS Analytics Showcase Platform

This repository provides an integrated clinical programming, epidemiological analytics, and reporting showcase combining **SAS (OnDemand for Academics / local)** via `saspy`, **Python**, and **R**.

---

## 1. Showcase Architecture & Core Pillars

The repository is structured into three primary analytical pillars:

1. **CDISC Clinical Data Pipelines**:
   - SDTM and ADaM dataset processing.
   - Demographics (`DM`) and Trial Arms (`TA`) handling.
   - Standardized macros in SAS, R, and Python for ISO 8601 date parsing, CDISC study-day interval derivation ($\text{EndDate} - \text{StartDate} + 1$), and treatment epoch assignment.

2. **Interactive Epidemiological Analytics Dashboard**:
   - Web application built with Python/Flask interfacing with SAS Cloud (ODA) in real time.
   - Live query engine on the European Centre for Disease Prevention and Control ([ECDC COVID-19 Vaccine Tracker](https://data.europa.eu/data/datasets/covid-19-vaccine-tracker), 813k+ records).
   - Generates publication-styled vector graphics and summary tables using SAS `PROC SQL`, `PROC SGPLOT`, and `ODS HTML`.
   - Dual-store architecture with local columnar Apache Parquet caching for sub-second dataset introspection.

3. **Specialized SAS Epidemiological Research Projects**:
   - **Dutch PHFS Burden of Disease Modeling** (`projects/dutch_phfs_burden_of_disease/`): Replicates the Dutch Public Health Foresight Study (VTV-2024 / Hilderink et al. 2025). Ingests hospital morbidity and mortality statistics from Statistics Netherlands (CBS Open Data via `cbsodata`), computes stratified Disability-Adjusted Life Years ($\text{DALY} = \text{YLL} + \text{YLD}$), and compiles high-resolution publication PDF reports via native SAS macros.
   - **Global Longevity Determinants General Linear Model** (`projects/longevity_linear_model/`): Implements an ANCOVA and multiple regression analysis (`PROC GLM`, `PROC REG`, `PROC UNIVARIATE`) on WHO and World Bank development indicators, evaluating the relationship between health expenditures, logarithmic GDP, and life expectancy.

## 2. 60-Second Quickstart Demo

No SAS license or credentials are required to explore the showcase. Run the complete multi-pillar demonstration in one command:

```bash
# 1. Run terminal walkthrough (CDISC derivations, DALY rankings, GLM parameter estimates)
python demo.py

# 2. Or launch the interactive analytics explorer directly in standalone demo mode
python demo.py --web
```

When running `--web`, open **`http://127.0.0.1:5000`** in your browser to interact with the multi-cohort selection wizard and review pre-rendered SAS ODS reports.

### Pre-Rendered Showcase PDF Reports
Representative PDF outputs generated by the platform are viewable directly on GitHub:

## 4. Prerequisites & Environment Setup

### A. Python Environment
A standard Python 3.10+ environment is required. Dependencies can be installed using `pip` or `uv`:
```bash
cd python
pip install -r requirements.txt  # or: uv pip install -r requirements.txt
```

Key dependencies:
- `saspy`: Official Python interface to SAS (IOM client).
- `pandas` & `pyarrow`: High-performance data manipulation and Parquet caching.
- `flask`: Web framework powering the epidemiological explorer.
- `pypdf`: Automated structural verification of generated ODS PDF reports.
- `cbsodata`: Statistics Netherlands open data interface.

### B. SAS Connectivity & Credentials
The platform communicates with SAS OnDemand for Academics (ODA) or local SAS 9.4+ via the IOM bridge.

1. **Authentication (`_authinfo`)**:
   Credentials for SAS ODA are stored securely in your user home directory:
   - **Linux/macOS**: `~/_authinfo`
   - **Windows**: `%USERPROFILE%\_authinfo`
   
   Format:
   ```text
   oda user your_email@example.com password your_password
   ```
   > Keep this file private with restricted permissions (`chmod 600 ~/_authinfo`). Never commit credentials to source control.

2. **Java Runtime**:
   SAS IOM socket communication requires a Java Runtime Environment (Java 8 JRE is recommended for compatibility with SAS ODA ciphers). Configure the Java binary path in `python/sascfg_personal.py` or via the `JAVA_HOME` environment variable.

3. **Connection Verification**:
   Verify your SAS connection independently with:
   ```bash
   python python/test_sas.py
   ```

## 5. Running the Pipelines & Research Projects

### A. Clinical Data Derivations

- **R Clinical Pipeline**:
  ```bash
  Rscript R/pipeline.R
  ```
- **Python / Pandas Pipeline**:
  ```bash
  python python/pipeline.py
  ```
- **Remote SAS Pipeline (via `saspy`)**:
  ```bash
  python python/pipeline_sas.py
  ```

### B. Epidemiological Analytics Dashboard

Launch the Flask web dashboard:
```bash
python python/dashboard/app.py
```
Open **`http://127.0.0.1:5000`** in your browser.
- Select target countries, reporting years, and age cohorts.
- The dashboard executes dynamic SAS SQL aggregations and generates vector charts and audit tables directly from SAS Cloud.
- Automatic failover: if SAS ODA is unreachable, processing gracefully falls back to local Pandas.

### C. Dutch Burden of Disease (DALY) Study
```bash
python projects/dutch_phfs_burden_of_disease/run_vtv_trendscenario_sas.py
```
- Fetches hospital morbidity from CBS Open Data table `84067NED`.
- Derives YLL, YLD, and total DALYs across age and gender strata.
- Compiles the publication-quality Nature-style PDF report via SAS ODS.

### D. Global Longevity Determinants GLM
```bash
python projects/longevity_linear_model/run_model.py
```
- Fits an ANCOVA model in native SAS evaluating $\ln(\text{GDP})$, health expenditure share, and regional adjustments against life expectancy.
- Extracts ANOVA tables, parameter estimates, and diagnostic metrics into Pandas DataFrames.
- Downloads the rendered statistical PDF report.

## 7. Security & Data Integrity Principles

- **Zero Hardcoded Secrets**: All API tokens and credentials are strictly loaded from environment variables or OS-level `_authinfo` files.
- **Privacy Protection**: Confidential datasets, assessment files, and large virtual environment archives are barred via `.gitignore`.
- **Grounded Scientific Claims**: Public datasets are attributed directly to their canonical providers (ECDC, Statistics Netherlands, WHO, World Bank) with explicit methodological citations.
